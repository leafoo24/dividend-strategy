# 策略选股初版实施计划

目标：在现有 React/Vite 产品新增单按钮选股页，运行服务器端 Tushare 质量增强红利策略，展示所有子指标。用户已批准实施。

1. 独立纯函数模块：TTM、年度分红归集、750日均值、60日复权收益波动、严格缺失值判定、筛选及排名。先用 node:test 覆盖未来公告、零利润、三年分红、支付率及单位边界。
2. 独立 Vite API 插件：服务器端读取已有 TUSHARE_TOKEN，执行异步任务并返回进度，缓存公开行情到独立目录；不修改现有 local-api/local-db 和业务数据。使用上一完整交易日数据，指数采用该日之前最近快照，行业使用当前申万分类并明示；仅支持当前选股，不宣称历史回测。
3. 新页面：唯一主要按钮“选股”，加载/失败/空结果/完成状态，横向滚动表格展示全部指标，保留任务状态；只新增导航和插件入口。
4. 检验：纯函数和API集成测试、现有测试、生产构建、真实接口小样本及浏览器页面检查。完整扫描有权限问题必须显示失败，不回退到模拟名单。

固定口径：PE TTM (0,25]，PB>0，股息TTM>3%，750交易日平均>2.5%，60日年化样本标准差保留池内最低90%，20日日均换手率>2%；连续三个年报年度已实施现金分红、年及三年累计支付率(0,1]、三年逐年扣非及最新TTM扣非盈利>0，最新每股现金分红不下降；发生送转影响可比性则排除并记数据不足。非金融企业现金流TTM/归母利润TTM>0.5；金融业该项不适用。无歧义增长率条件未纳入。利润年初累计值转TTM，公告晚于基准日不可使用。分红采用实施且除息日已到的记录，不混合预案和实施。
